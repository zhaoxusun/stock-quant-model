================================================================================
从量化策略到AI模型：我用XGBoost蒸馏了一套交易系统，在未见过的股票上准确率98.3%
================================================================================

核心观点：一套基于成交量和均线的规则策略，经过35维特征工程 + XGBoost多标签
分类蒸馏，得到的AI模型在完全没见过的股票上达到98.3%的信号级准确率——4种信号
类型分别独立预测，不合并、不加权、不排序。


引子：一个经典的问题
====================

做量化交易的人可能都遇到过这样的困境：

规则策略 — 逻辑透明、可解释性强，但参数调优困难、市场环境变化时需要手动调整。

机器学习模型 — 能自动学习复杂模式，但往往像个黑箱，难以信任，而且容易过拟合。

有没有一种方式，能把两者的优点结合起来？

答案是用规则策略的信号输出作为训练标签，让模型去学习策略的决策逻辑。这就是
"策略蒸馏"（Strategy Distillation）——不直接预测涨跌，而是预测策略会给出
什么信号。

本文完整记录了我对 EnhancedVolumeStrategy 策略进行蒸馏的全过程：从特征工程
到多标签模型训练，再到在完全未见过的股票上进行独立验证。


一、背景：EnhancedVolumeStrategy 是什么
=========================================

这是一个基于成交量放大 + 均线背离的复合交易策略，核心逻辑是：

1. 检测放量：当日成交量超过动态阈值（均量 x 波动乘数）
2. 检测K线形态：连续3根阴线（买入时机）或连续3根阳线（卖出时机）
3. 检测均线偏离：价格偏离均线的幅度
4. 复合评分：成交量偏离度 x 均线偏离度，得到信号强度

策略输出4种信号类型，独立触发，无优先级覆盖：

  normal_buy   普通买入信号    常规开仓
  normal_sell  普通卖出信号    常规平仓
  strong_buy   强买入信号      加大仓位
  strong_sell  强卖出信号      强制平仓

同一天可以同时出现 normal_buy + strong_buy，两种信号各自独立。


二、蒸馏目标：让模型学会策略的决策边界
=========================================

2.1 为什么不用模型直接预测涨跌？

传统方法是用未来的收益率做标签训练模型，但这有几个问题：
- 未来收益充满噪声，信噪比极低
- 模型学到的是统计巧合而非因果关系
- 样本外表现往往大幅回撤

策略蒸馏的思路完全不同：用策略本身的输出做标签，模型去拟合策略的决策函数。
这相当于把一套可解释的规则策略，压缩成一个更快、更平滑、更泛化的树模型。

2.2 多标签分类设计

策略蒸馏不是简单地预测"买入/卖出/持有"三分类。因为一天可能同时有买入和卖出
信号，我采用了多标签分类——4个独立的二分类器并行预测：

  MultiOutputClassifier
     +-- XGBoost #0 -> normal_buy?  (是/否)
     +-- XGBoost #1 -> normal_sell? (是/否)
     +-- XGBoost #2 -> strong_buy?  (是/否)
     +-- XGBoost #3 -> strong_sell? (是/否)

每个分类器使用相同的35维特征，但学习不同的决策边界。

关键设计决策：
- 不合并、不加权、不排序 — 4路信号完全独立输出
- 不做优先级覆盖 — 即使 strong_buy 触发，normal_buy 也正常输出
- prediction API 返回原始信号矩阵 — 调用方自行决定如何使用


三、35维特征工程
=================

特征是一切的上限。我完全复刻了 EnhancedVolumeStrategy 内部计算的所有中间变量，
作为模型的输入特征：

量价原始数据（5维）
  open high low close volume

均线系统（4维）
  ma_vol_5    = volume.rolling(5).mean()
  ma_vol_20   = volume.rolling(20).mean()
  ma_close_5  = close.rolling(5).mean()
  ma_close_20 = close.rolling(20).mean()

波动率（2维）
  vol_std_5  = volume.rolling(5).std()
  vol_std_20 = volume.rolling(20).std()

RSI（1维）14周期RSI

布林带（3维）20周期布林带（2倍标准差）

KDJ（4维）9周期KDJ指标 rsv k d j

成交量动态阈值（2维）
  vol_multiplier_5  = 0.9 + min(vol_std_5 / ma_vol_5, 0.6)
  vol_multiplier_20 = 0.8 + min(vol_std_20 / ma_vol_20, 0.5)

成交量背离度（2维）
  vo_count_5  = max(0, volume - ma_vol_5  x vol_multiplier_5)
  vo_count_20 = max(0, volume - ma_vol_20 x vol_multiplier_20)

K线形态（2维）
  is_3_up   = 连续3根阳线      潜在卖出信号
  is_3_down = 连续3根阴线      潜在买入信号

均线偏离度（4维）
  ma_count_buy_5   = max(0, ma_close_5  - close)
  ma_count_sell_5  = max(0, close - ma_close_5)
  ma_count_buy_20  = max(0, ma_close_20 - close)
  ma_count_sell_20 = max(0, close - ma_close_20)

复合信号强度（6维）
  buy_signal_5   = -vo_count_5 x ma_count_buy_5    5日框架买入复合分
  sell_signal_5  =  vo_count_5 x ma_count_sell_5   5日框架卖出复合分
  buy_signal_20  = -vo_count_20 x ma_count_buy_20  20日框架买入复合分
  sell_signal_20 =  vo_count_20 x ma_count_sell_20 20日框架卖出复合分
  buy_signal_count  = 买入信号计数器 (0/1/2)
  sell_signal_count = 卖出信号计数器 (0/1/2)

总计35维特征，全部是原始策略内部计算过的指标。模型的任务不是"发现新模式"，
而是学习策略如何将这些指标组合成最终的信号决策。

五、模型训练
=============

5.1 XGBoost 超参数

  参数                 值                说明
  ------------------------------------------------
  objective      binary:logistic     二分类对数损失
  max_depth      8                   树深度
  n_estimators   300                 树数量
  learning_rate  0.1                 学习率
  subsample      0.8                 行采样
  colsample_bytree 0.8              列采样
  min_child_weight 3                 叶子节点最小权重
  gamma          0.1                 分裂最小损失下降
  random_state   42                  随机种子

选择XGBoost而非深度学习的原因：
1. 表格数据上树模型通常优于DNN
2. 特征重要性可解释
3. 对缺失值和不平衡数据天然鲁棒
4. 训练速度快，超参数调优成本低

八、误报和漏报分析
===================

8.1 FP（误报）：模型有信号，但实际策略没有

  2022-07-13  normal_buy     招商银行处于阶段性底部区域，模型认为是买入
                              机会，但策略参数未触发

  2022-07-14  normal_buy +   同日两个买入信号——模型判断强烈看多，但策略的
              strong_buy     风控规则（如仓位、资金）可能阻止了信号生成

  2025-02-27  strong_sell    模型认为应强卖出，但策略未标记

值得注意的是，"误报"不一定代表模型错了。策略的信号生成有额外的约束条件
（如持仓状态、资金管理、最小间隔等），而模型只学习"这种K线形态下策略通常
会给什么信号"。策略本应在某些日期触发但因外部约束被抑制的信号，模型反而
"自由"地输出了。

8.2 FN（漏报）：实际策略有信号，但模型没有

  2025-11-04  strong_sell    唯一一次漏报。该日策略触发的阈值条件刚好卡在
                              边界上，模型输出概率略低于0.5

8.3 误差总结

在 981 个交易日中：
- 无信号日：922 天（模型全部正确预测为无信号）
- 有信号日：59 天（模型正确预测 58 天）
- 总错误：4 天（3 天误报 + 1 天漏报，其中1天同时有2个信号误报）

假阳性率（FPR）= 3/922 = 0.33%，每300个无信号交易日才出现1次误报。
假阴性率（FNR）= 1/59 = 1.7%，每59个信号日才漏掉1个。


九、一些思考
=============

9.1 为什么选择"策略蒸馏"而不是"直接预测"

策略蒸馏的本质是知识迁移：

  规则策略（可解释、稳定） -> XGBoost 模型（快速、泛化）

而不是：

  价格数据（噪声多） -> 模型（容易过拟合）

前者学的是策略的"思维模式"——一个已经验证有效的交易逻辑；后者学的是
"碰巧涨了"——充满统计陷阱。

9.2 多标签设计的意义

传统量化研究往往把信号合并成一个"最终信号"（如-2到+2的评级），这丢失了
信息。多标签设计保留了信号维度的正交性：
- 一个日期可以同时有买入和卖出信号（不同时间框架）
- 调用方可以根据自己的持仓和风控选择合适的信号
- 强信号和普通信号独立决策，互不干扰

9.3 独立样本外验证的价值

模型在训练集上的 F1 高达 99.5-100%，但这可能是过拟合的假象。真正有说服力
的是样本外验证。

招商银行的选择很苛刻：
- 行业不同：训练集全是科技/互联网/消费/白酒，而招商银行是银行板块
- 走势不同：银行股波动率低、股息率高、走势特征与科技股差异明显
- 完全未见：招商银行没有任何信号文件参与训练

在这样的条件下达到 94.3% 的 F1，说明模型确实学到了与行业无关的通用交易逻辑。


十、局限性和未来方向
=====================

已知局限：

1. 单一日线框架：模型仅基于当日特征做判断，不包含序列建模。引入LSTM或
   Transformer做时序编码可能会进一步提升。
2. 交易约束缺失：模型学不到策略的持仓管理规则。
3. 阈值固定：当前使用固定的0.5阈值，可以通过验证集调优每个分类器的最佳阈值。
4. 行业覆盖不足：目前仅覆盖科技/消费/白酒/银行。

未来方向：

1. 特征增强：引入宏观因子、市场情绪指标
2. 序列建模：将日线窗口作为输入，用CNN或Transformer提取时序特征
3. 多策略融合：同时对多个策略进行蒸馏，使用多任务学习
4. 在线学习：定期用新的K线数据和策略信号更新模型


结语
=====

回到开头的问题：规则策略还是机器学习？

我的答案是都要。

规则策略提供了可解释、稳定的交易逻辑——这是"道"；机器学习提供了自动化的
特征组合、平滑的决策边界——这是"术"。用规则策略做导师，用机器学习做学生，
是量化研究的一个高效路径。

招商银行的样本外验证给了我们信心：当一个XGBoost模型在完全没见过的股票上
达到98.3%的信号准确率时，它绝不是随机记忆，而是学到了真正的交易模式。
